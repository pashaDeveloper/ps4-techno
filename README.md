# PS4 Host Collection

این پروژه یک سایت استاتیک است و به Docker، نصب وابستگی یا مرحلهٔ build نیاز ندارد.

## اجرای محلی

با Python 3، از ریشهٔ پروژه اجرا کنید:

```powershell
py -m http.server 8080 --bind 127.0.0.1
```

در لینوکس یا macOS:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

سپس آدرس http://localhost:8080 را باز کنید. این سرور برای تست محلی است.

## میزبانی

فایل `index.html` و پوشه‌های زیر را با حفظ ساختار در ریشهٔ سایت روی یک وب‌سرور استاتیک قرار دهید:

- `13xxgr/`
- `505n672/`
- `900f/`
- `g2all/`

## Coolify

این مخزن Dockerfile ندارد. برای میزبانی در Coolify از روش Static استفاده کنید و ریشهٔ مخزن را به‌عنوان مسیر فایل‌های سایت انتخاب کنید. پروژه دستور نصب یا build ندارد.

Coolify همچنان سایت استاتیک را داخل کانتینر اجرا می‌کند؛ حذف Dockerfile وابستگی خود Coolify به Docker را حذف نمی‌کند. خطای `runc ... EOF` هنگام شروع کانتینر باید روی سرور مقصد بررسی شود.
